# CakeControl (Frontend)

ระบบหน้าบ้านของโปรเจค พัฒนาด้วย React 19 และ Vite 7 ออกแบบมาในสไตล์ Premium (Glassmorphism & Dark Mode)

## เทคโนโลยีที่ใช้
- React 19
- Vite 7
- Vanilla CSS (Custom Theme & Variables)

## วิธีการรัน (How to run)

1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```

2. รันโหมด Development (รันบน Localhost):
   ```bash
   npm run dev
   ```

3. สร้างไฟล์ Build สำหรับ Production:
   ```bash
   npm run build
   ```
